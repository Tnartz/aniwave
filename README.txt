AniWave — статический демонстрационный сайт

Публикация:
1. Откройте https://vercel.com/ и войдите или создайте аккаунт.
2. Установите Vercel CLI либо импортируйте этот проект через GitHub.
3. Для самого простого варианта загрузите папку проекта в GitHub, затем в Vercel выберите Add New -> Project и импортируйте репозиторий.
4. Framework Preset: Other. Build Command и Output Directory оставьте пустыми/по умолчанию для статического index.html.
5. Нажмите Deploy. Vercel выдаст публичный адрес вида https://....vercel.app.

Ограничения:
- Это frontend-прототип. Демо-вход не является настоящей авторизацией.
- Избранное хранится локально в браузере.
- Видеопоток, лицензии на контент, база пользователей и платежи не подключены.
- Перед коммерческим запуском добавьте серверную авторизацию, БД, проверку подписок и лицензированные видеоисточники.
